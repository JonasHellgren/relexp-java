# Reinforcement Learning Explained – Java Code

This repository contains the Java source code accompanying the book
**Reinforcement Learning Explained**.

The examples are designed to illustrate reinforcement learning concepts
through small, practical implementations.

## About the Book

*Reinforcement Learning Explained* provides a practical introduction to
reinforcement learning and self-learning agents.

The focus is on understanding how reinforcement learning algorithms work
by implementing and experimenting with them.

More information about the book:

**https://relexp.com**

## Repository Structure

The code is organized according to the examples and topics presented in
the book.

Each example is intended to be small enough to study independently while
demonstrating a specific reinforcement learning concept.

## Requirements

- Java
- Maven

See the individual projects for additional requirements and instructions.

## Python Version

A Python implementation of the book examples is available in a separate
repository:

**relexp/relexp-python**

## Purpose

The code is primarily intended for learning and experimentation rather
than production use.

Readers are encouraged to modify the examples, change parameters, and
experiment with the algorithms.
